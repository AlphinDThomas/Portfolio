ML System for Dysarthric Speech
Designed and developed an Automatic Speech Recognition (ASR) system that improves intelligibility of dysarthric speech — making technology more accessible for speech-impaired users. Fine-tuned OpenAI's Whisper Base model on the TORGO dysarthric speech dataset using parameter-efficient techniques.
  • Fine-tuned Whisper Base using dysarthric speech audio from the TORGO dataset
  • Applied PEFT with LoRA architecture — only ~200,000 trainable parameters needed
  • Enabled accurate conversion of dysarthric speech to text, drastically improving accessibility
🏆  Outperformed OpenAI's Whisper Medium — a significantly larger model — on dysarthric audio transcription benchmarks, despite having far fewer parameters.

Computer Vision Security 2025 – 2026
PulseGuard
A comprehensive, web-based identity verification and liveness detection system — a modern e-KYC pipeline. Unlike traditional verification that merely asks "does this face match the ID?", PulseGuard simulates a layered security checkpoint that defeats deepfakes, spoofing attacks, and pre-recorded videos through a strict four-stage state machine.
Stage 01
Identity Match
Compares live webcam face against a 128-dim dlib face embedding stored in Supabase
Stage 02
Passive Liveness
Simulated rPPG — analyzes micro skin-color variations to verify a human heartbeat
Stage 03
Cognitive Challenge
Randomized finger-count challenge via MediaPipe Hands defeats pre-recorded video attacks
Stage 04
Spatial Awareness
3D PnP math tracks yaw/pitch — forces random head turns that real deepfakes can't handle
